# northwind-service-desk-agent

Work in progress. A portfolio project: an IT and HR service-desk agent for a fictional company
(Northwind Ltd) that handles access requests, policy questions and device checks safely,
built with Microsoft Agent Framework (Python), MCP tools and a mock Microsoft Graph server.

All data is synthetic. See `DECISIONS.md` for design decisions. The full README (architecture,
results with confidence intervals, limitations) is written in Phase 7.
